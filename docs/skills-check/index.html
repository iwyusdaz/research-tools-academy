Skills check

Nine short scenarios drawn from the situations in our support question analysis — three per learning path. Each answer gets specific feedback with a link back to the lesson that teaches it.

This is a learning aid, not a test. Wrong answers are the useful ones here: the feedback explains the actual cause. Results are shown by path at the end. Nothing is stored — no answers, no scores, no analytics.

Scenarios verified against the official Zotero documentation (Zotero 10.0.6) on 2026-10-25.
