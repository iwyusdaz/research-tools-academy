Troubleshooting tool

Guided, one-fix-at-a-time diagnosis for the five most common problems in our analysis of 145 real public support questions. Each fix comes from the official Zotero documentation, and each flow says honestly when a problem needs the official forums instead of a fix.

The five flows:

  1. The Zotero save button doesn't appear in my browser
  2. Saving fails: “Zotero is unavailable” — or items/PDFs never appear
  3. The Zotero tab is missing in Microsoft Word
  4. Citations show as ADDIN ZOTERO_ITEM codes — or won't update
  5. PDFs or changes won't sync across devices

How to use it: pick your problem, answer the questions, try one fix at a time. Use Back to undo a step and Start over to return here. Everything runs in your browser — nothing you click is stored or sent anywhere.

Flows verified against the official Zotero documentation (Zotero 10.0.6, released October 7, 2026) on 2026-10-25. Sources: support question analysis and the Zotero knowledge base.
