# Usability Test Script (facilitator)

*Prepared 2026-10-25. Not yet run. Pair with `consent-text.md` and `findings-template.md`. Target: 3–5 graduate students or researchers, ~30 minutes each, no personal data collected beyond session notes the participant approves.*

## Setup (before the participant arrives)

- Participant's own laptop if possible (that's the real environment — especially the Word-on-work-laptop case); otherwise a prepared machine with Zotero installed.
- Browser open to the academy home page. Word (or the participant's word processor) open on a blank document with a paragraph of text.
- One journal-article page bookmarked for Task 1 (a page with an abstract, not a PDF).
- Screen recording **off** by default; ask (consent text §3). If declined, rely on the findings template notes.

## Opening (3 min)

> "Thanks for helping. This is a learning site for Zotero built from real support questions. I'm testing the *site*, not you — any trouble you have is a design problem for me to fix. Think out loud as much as you can. There's no time limit and nothing you do here is graded or stored."

Confirm consent (see consent text). Answer questions about Zotero itself **only after** both tasks are done.

## Task 1 — Save a source and cite it (12 min)

> "You're starting a literature review. Using only this site — start from its home page — get this article saved into Zotero and cited in this Word document, in APA style."

Observe and note (findings template):

- Which path/lesson they choose from the home page; whether the choose-your-path table is understood.
- Whether they find and complete the connector install *if it's missing*.
- Where they look for the "check it worked" confirmation.
- Time to first citation; number of times they leave the academy for another source (it's allowed — note it).

Probes (only if stuck for > 2 minutes): "What would you expect to happen next?" · "Where on this page would you look for that?"

**Stop conditions:** the participant asks to stop, or 15 minutes elapse. Mark the step reached.

## Task 2 — Fix a broken thing (8 min)

> "Now imagine this: the Zotero tab has disappeared from Word. You don't know why. Using only this site, try to fix it."

(The facilitator has pre-hidden the tab by disabling the add-in, or simulates the symptom verbally if the participant's machine can't be modified.)

Observe:

- Whether they go straight to the troubleshooting tool or try lessons first.
- Whether they follow the flow's steps in order or skim.
- Whether the flow's "Did this solve it?" question makes sense at each step.
- Whether they reach the fix (or honestly-routed exit) and whether they trust it.

## Debrief (5 min)

1. "What was the most confusing moment?" 2. "Was anything patronizing or dumbed-down?" 3. "Would you use this instead of the official docs? When not?" 4. "What's missing that you expected?"

Answer their accumulated Zotero questions now.

## After the session

- Complete `findings-template.md` within an hour, while memory is fresh.
- No names in any artifact: participants are "P1"…"P5".
- After 3–5 sessions: write up the stuck-point list, propose revisions, and document every change in `CHANGELOG.md` with the session reference that motivated it (the ≥ 3 revisions requirement).
