## Synthesis across sessions (after 3–5)

1. List every stuck point; mark frequency (P1+P3 = 2 mentions).
2. Anything mentioned by ≥ 2 participants = a candidate revision.
3. Make the revisions, record each in `CHANGELOG.md` with the motivating session references (the "≥ 3 revisions documented" requirement), and re-run `npm run test:keyboard` plus the axe audit on changed pages.
